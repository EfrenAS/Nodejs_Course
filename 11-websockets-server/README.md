# WebSockets Server

## Descriptions

A simple WebSocket server implementation in Typescript, is part of the Nodejs course by Fernando Herrera, found in Udemy platform.

## What's learned

- WebSocket protocol client and server
- Typescript
- Nodejs

## Installation

Clone the repository:

```bash
git clone https://github.com/efren_as/websockets-server.git
```

Install dependencies:

```bash
cd websockets-server
npm install
```

or

```bash
yarn install
```

or

```bash
pnpm install
```
