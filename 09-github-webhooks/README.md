# Github Webhooks Project

## Description

This project is a simple implementation of a Github Webhook server using Node.js and Express.js. It listens for push events from Github repositories and triggers a build process when a new commit is pushed, and sends a notification to a Discord channel with a bot.

## Installation

1.- Config all the environment variables in the .env file.

2.- To install the dependencies, run the following command:

### npm command

```
npm install
```

### pnpm command

```
pnpm install
```

### yarn command

```
yarn install
```

## Development Mode

```
npm run dev
```

or

```
yarn dev
```

or

```
pnpm dev
```

or

```
pnpm run dev
```
